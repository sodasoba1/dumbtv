# Source and purpose of DumbTV's external DNS lists.
#
# Pi-hole blocklist exports are maintained under data/blocklists/pihole/:
#   v6/          Adblock/ABP format for Pi-hole v6
#   v5/          Adblock/ABP format for Pi-hole FTL 5.22+
#   v5-legacy/   plain domains for older FTL; exact hostnames only
#
# Upstream:
#   https://cdn.jsdelivr.net/gh/hagezi/dns-blocklists@latest/adblock/native.amazon.txt
#   HaGeZi's maintained Amazon native tracker list, in Pi-hole-compatible
#   Adblock format. Check its upstream licence and changelog.
#
# Local sources:
#   extra-hosts.txt       supplemental Amazon telemetry, advertising and update hosts
#   alexa-hosts.txt       optional Alexa voice/device endpoints
#   prime-video-hosts.txt opt-in Prime Video blocking endpoints
#
# Regenerate versioned Pi-hole exports after editing a source:
#   python3 scripts/export-pihole-lists.py --write
# CI checks that committed exports match these source files.
#   verify-blocked.txt / verify-allowed.txt are historical verification references
#
# Prime Video delivery and device-messaging endpoints are intentionally separate
# in data/blocklists/pihole/*/prime-video.txt. Do not add them to the default list.
# prime-video-allowlist.txt preserves the five AIV delivery/CDN entries in the
# current HaGeZi Amazon list when Prime Video playback is required. The separate
# prime-video.txt list is opt-in and should only be used to block Prime Video.
